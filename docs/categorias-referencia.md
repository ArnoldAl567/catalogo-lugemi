# Fotografías de categorías · Lugemi Kids

Las tres fotografías se reconstruyeron desde la referencia visual entregada por la tienda con la herramienta integrada ImageGen, sin API externa. Se revisaron visualmente y se exportaron a WebP de 800 × 800 para reducir la descarga en móviles.

Archivos finales:

- `public/images/brand/categoria-polos.webp`
- `public/images/brand/categoria-jeans.webp`
- `public/images/brand/categoria-conjuntos.webp`

Referencia: `codex-clipboard-76a4d679-1e87-4f04-a9db-c72b4abd7f2d.png` proporcionada por el usuario.

## Prompts finales

Se utilizó este prompt con cada uno de los tres sujetos descritos abajo:

> Use case: precise-object-edit. Input image is an existing website design; edit target is ONLY [subject]. Extract that exact photograph into a standalone square editorial category image for the Lugemi Kids website. Preserve the same person, face, clothing, pose, garment details, warm lighting, palette and background as closely as possible. Remove all surrounding website UI, other panels, borders, category labels, arrows and typography outside the clothing. Extend only the photographic backdrop if needed to fill a square canvas; do not redesign the photo or add people. Full-bleed photograph, no rounded border, no caption, no watermark. This is an asset extraction from the supplied reference, not a new website mockup.

Sujetos utilizados, respectivamente:

1. the LOWER LEFT category photograph: smiling curly brown-haired boy in a cream polo with navy collar and tiny Lugemi L chest monogram, against a warm beige wall
2. the LOWER CENTER category photograph: close crop of blue denim cargo shorts worn by a child, from waist to knees, hands in pockets, warm beige backdrop
3. the LOWER RIGHT category photograph: smiling long brown-haired girl wearing a cream hooded sweatshirt with tiny Lugemi L chest monogram, warm beige backdrop

La portada del campo procede directamente del archivo entregado por el usuario. Su versión WebP está en `public/images/brand/lugemi-portada-campo.webp`; no se ha generado otra escena.
