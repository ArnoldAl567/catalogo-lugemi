# Fotografías de producto — Lo más elegido

Se crearon con la herramienta integrada ImageGen a partir de las fotos ilustrativas de las mismas prendas. Cada imagen muestra una única prenda sobre fondo marfil. Resolución nativa conservada: 1254 × 1254 px; WebP calidad 95, sin ampliación artificial. Las imágenes con modelos se mantienen en las categorías y como vista alternativa en las fichas. Las tarjetas compactas de destacados solo muestran la prenda completa, sin cambio de foto al pasar el cursor.
